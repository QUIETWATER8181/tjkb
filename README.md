# 课表提醒助手

一个轻量的课表管理与提醒工具，单文件网页应用，双击即可使用，无需安装。

## 在线使用

直接访问 GitHub Pages 在线版本：

**https://quietwater8181.github.io/tjkb/**

## 功能

- **今日概览**：当日课程列表（带上课状态）、下节课倒计时、今日待办
- **课表管理**：11 节次 × 7 天网格课表，标注午休/晚休，左侧显示上课时间
- **课程编辑**：单击格子添加/编辑课程，长按拖拽移动，上下边缘拖拽调整长度
- **周次管理**：支持 16 周学期，课程可按周次（全部/范围/单周/双周/自定义）设置
- **提醒事项**：待办清单，按考试/作业/活动/个人分类，到期高亮
- **截图识别**：粘贴课表截图自动识别课程信息（需联网，辅助功能）
- **数据管理**：数据保存在浏览器本地，支持 JSON 导出/导入备份

## 使用方式

1. 在线版：直接打开上方链接使用
2. 离线版：下载 `index.html`，双击在浏览器中打开即可

> 注意：数据保存在浏览器的 localStorage 中。清除浏览器数据会丢失内容，建议定期在"设置"中导出备份。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，零依赖，单文件
- OCR 识别使用 Tesseract.js（按需从 CDN 加载）
- 无后端服务器，所有数据仅在本地浏览器中存储
